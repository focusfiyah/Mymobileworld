# Per-second logic and entertainment gate

One absurd second reads as careless AI and sinks the video, however good the rest. Write one plain sentence per second of what
is on screen ("12 s: she lifts the tube, the cap is already off"). A sentence that sounds absurd fails the logic list; one that
adds nothing fails the entertainment list. Run it on the plan, on each clip, and on the final frames.

## Logic

1. Persistence: what exists stays where it was; nothing re-spawns; entrances and exits are visible.
2. No morphs: one object never turns into another (a product, a hand, a cap).
3. Cause before effect: each change has a visible cause in that second or the one before.
4. Physics holds: grips, liquids, counts (two hands stay two hands).
5. Words equal picture in the same second: each spoken noun and number is on screen (matches Ralph's rule, not excessive).
6. Identity holds: same person, outfit, product and room in every shot.
7. One light source per place; time of day changes only with a cue.
8. The camera has a reason: it moves to answer what was just said and holds while information lands.

## Entertainment

1. Something new every 2 to 3 seconds (a reveal, a change, a fact).
2. Each beat opens or pays off a question; list plant and payoff times and pay each one.
3. Escalate: each beat beats the last.
4. Second person ("your") and a unit from the viewer's life.
5. The surprise is fair: set up before it lands.
6. Reads with the sound off for Day One AI and story reels (on Grace's ads there is no on-screen text unless Ralph says).

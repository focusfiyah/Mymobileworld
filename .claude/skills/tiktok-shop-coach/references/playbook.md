# TikTok Shop playbook

Working craft knowledge for breakdowns and scripts. These are patterns, not laws. When a real winning video in the
niche contradicts them, follow the video.

## Breakdown checklist (use this order)

1. **Hook, 0–3 s.** Three layers, read each one:
   - Spoken: the first sentence, word for word.
   - On-screen text: what it says and when it appears (hook.png shows it frame by frame).
   - Visual: what's in frame at 0 s. Product, face, result, motion, or something odd?
   Name the hook type (list below). Does the first second make sense with the sound off?
2. **Structure.** Beats with timestamps from transcript.vtt: hook → problem/context → product → proof/demo → CTA.
   Note when the product first appears and how long until the first proof.
3. **Proof.** What makes it believable: live demo, before/after, texture close-up, price on screen, receipts,
   dashboard screenshots, reactions.
4. **CTA.** Exact words and placement ("orange cart", "link below", "first link in bio"). Is there a reason to buy now
   (a real deal, seasonality)?
5. **Numbers in context.** views ÷ creator followers (>1 means the video traveled beyond the audience), engagement %,
   save % (saves ≈ "I'll buy or try this later"), length, posted date, sound (original voice vs trending audio).
6. **Verdict.** Why it worked or flopped, in 2–3 sentences, then what to copy (the pattern, not the words).

Reading a retention screenshot: a steep drop in the first 1–2 s means the hook failed (the opener didn't match what
the viewer expected or nothing moved). A slow slide in the middle means pacing (a beat runs too long, there's a
repeat, or proof is missing). A drop just before the CTA means the payoff came too early. Match each drop's second
to the transcript line.

## Hook types

| Type | Shape | Example pattern |
|---|---|---|
| Problem call-out | Name a pain the viewer has | "If your ___ keeps ___, watch this." |
| Result first | Show the end state, then rewind | Finished look / clean result in frame 1 |
| Comment reply | Reply-to-comment sticker + answer | "My Shop videos always flop, any advice?" |
| Curiosity gap | Promise a reveal, delay it | "One thing made the difference, and it's not the obvious one." |
| Contrarian | Push back on common advice | "Stop posting 10 times a day. Do this instead." |
| Price shock | Lead with price or deal | "$27 and it does what my $90 one did." |
| Visual pattern break | Odd motion or object at 0 s | Squish, pour, rip, drop, before-after split |
| POV / skit | Relatable scene | "POV: you finally found jeans that fit" |
| Social proof | Others' reaction or numbers | "This sold out twice this month" (only if true) |
| Direct address | Name the viewer | "TikTok Shop affiliates, you could 10x your earnings" |

Strong hooks stack two layers: e.g. a spoken problem call-out + text showing the result + the product moving in frame.

## Script frameworks

- **PAS (problem, agitate, solve):** pain → why the usual fixes fail → product → demo → CTA. Good for problem-solvers.
- **Result-first:** result → "here's how" → 2–3 quick steps or features → proof → CTA. Good for beauty, cleaning, home.
- **Unboxing to demo:** package in frame at 0 s → first reaction → feature tour with close-ups → price → CTA.
- **Comparison:** expensive/known option vs this one, same test on both, honest result → CTA.
- **Listicle:** "3 things I'd buy again from TikTok Shop", fast cuts, a reason for each one → CTA on the best.
- **Story/POV skit:** a relatable moment → product saves it → reaction → CTA (see `ugc-product-ad` for skits).
- **Bottom-of-funnel (BOF):** for viewers already shopping: price, deal, what's included, size/color options, shipping,
  "tap the orange cart". Short (10–20 s). Pair with top-of-funnel hooks for reach.

Script format to deliver:

```
HOOK (0–2s)  Say: "..."   Text: "..."   Shot: ...
0:02–0:08    Say: "..."   Text: "..."   Shot: ...
...
CTA          Say: "..."   Text: "..."   Shot: ...
Caption: ... #ad / commission disclosure + 3–5 hashtags
```

## Buyer-psychology levers (use only the true ones)

- **Specificity.** Exact numbers and details beat adjectives ("dries in 4 minutes" vs "dries fast").
- **Seeing is believing.** Demo on camera, texture close-ups, real use in a real place.
- **Price anchoring.** Compare to a real higher-priced alternative or the regular price.
- **Timeliness.** Seasonal moments (back to school, Halloween, gifting season), real limited deals.
- **Identity.** "For moms who...", "if you're short...". Viewers buy what fits who they are.
- **Risk reversal.** Real return policy, size guidance, "what I'd change about it" builds trust.
- **Social proof.** Reviews, reactions, sold counts, but only ones the user can show.

## Product scorecard (score 1–5 each)

| Factor | What to look at |
|---|---|
| Demand | Lifetime sold, rating and reviews (`shop`); recent high-view videos (`discover`, `tag`) |
| Competition | How many recent videos exist; whether big creators dominate (crowded) or small ones hit (open) |
| Commission | Commission % × price = earnings per sale |
| Demo-ability | Is the benefit visible in 3 seconds on camera? |
| Fit | Matches the creator's audience and past winners |
| Timing | Seasonal upswing now, or fading? |
| Trust risk | Reviews mention quality issues, sizing problems, slow shipping? (score lower) |

Rank by total, but call out a product that's 5 on demand and demo-ability even if competition is high. Label every
number with its source (TikTok Shop page, video page, their screenshot, or estimate). Lifetime sold is not recent sales.

- The default browser tool in every session is camofox-browser (github.com/jo-inc/camofox-browser, MIT, npm 1.18.1; Camoufox = anti-detection Firefox 152.0.4-beta.30). `.claude/hooks/camofox_setup.sh` (SessionStart, Mymobileworld + Dayone-ai) installs it in the background (~1 min cold, ~1.3 GB), trusts the proxy CAs through Camoufox's enterprise policy and starts the REST server on 127.0.0.1:9377, log `/tmp/camofox-setup.log`; `.mcp.json` runs the thin MCP adapter `@askjo/camofox-browser-mcp@1.18.1` (11 tools: `camofox_create_tab`, `_snapshot`, `_click`, `_type`, `_navigate` incl. search macros like `@google_search`, `_evaluate`, `_screenshot`...). Telemetry OFF (`CAMOFOX_CRASH_REPORT_ENABLED=false`; it reports crashes to the maker by default). Its npm downloader cannot reach api.github.com here (403), so the hook downloads the browser zip directly. The environment's Setup script registers camofox-browser at user level next to the Playwright MCP (Ralph updated it 2026-10-24), so the tools appear even when a session starts outside the repos; the server itself still comes from the hook. If the tools fail, run `bash /home/user/Mymobileworld/.claude/hooks/camofox_setup.sh` and wait for CAMOFOX_SETUP_OK.

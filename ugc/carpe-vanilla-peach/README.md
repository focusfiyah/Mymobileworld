| Signal | Number | Source |

| Hard-sell format | "please stop buying this… flash sale… ends tonight": 830k views but **0.02% saves** | [@yourboybigmike](https://www.tiktok.com/@yourboybigmike/video/7603578180678470926) |
| Scent | creators talk about the smell in almost every positive video | @kellylandsman (150k), @ashtonshep (218k) |

**Pick:** a hands-only "watch this before you use it" tips video. It is the format with the most views *and* the
most saves, it answers the three complaints that went viral (they're all usage mistakes Carpe's own guide covers),
and every tip is something hands can show. The hard-sell style gets views but almost no saves, which is why the
first draft (feature list, "grab it from the orange cart") read like an ad.

**Length:** Carpe videos run median 35s (all 72), 41s (10k+ views), 55s (100k+ views, but those are talking-head
videos with rambling). A faceless hands video has less to hold attention, so 36s sits at the median without padding.
